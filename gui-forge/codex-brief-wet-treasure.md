# 젖은 보물상자 추첨 배경 발주서

## 산출 규격

- 캔버스: `704×672px` (`176×168 GUI px`, 3행 27칸)
- 원본: `src/wet_treasure/bg_raw.png`
- 맞춤본: `src/wet_treasure/bg_source.png`
- 최종 글리프: `wettreasure_` 12타일, `U+E860~U+E86B`
- 제목은 코드가 얹으므로 그림에 글자·숫자를 넣지 않는다.

## 슬롯 역할

- `0~8`, `18~26`: 장식. 젖은 상자 프레임과 밧줄·물방울을 보여준다.
- `4`: 당첨 위치 표식이 올라가는 홈.
- `9~17`: 매 틱 보상 아이콘이 바뀌는 릴. 어두운 평판으로 유지하고 칸 테두리는 그리지 않는다.
- `22`: 추첨 상태 아이콘 홈.
- 플레이어 인벤토리 영역: 아이템 격자는 빌더가 합성하므로 원화에는 그리지 않는다.

## 아트 방향

젖은 표류목, 검은 철띠, 녹슨 구리, 청록색 바닷물 발광을 사용한다. 중앙 릴은 아이콘
가독성을 위해 낮은 대비로 비우고, 상단에는 제목이 읽힐 어두운 명판을 둔다. 하단에는
짙은 남청색 평판과 얕은 물결만 남긴다. 배경은 완전 불투명이어야 한다.
