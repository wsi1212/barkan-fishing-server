**배경판·소켓은 등급 무관 1장씩**이고, 등급별로 갈리는 건 제단뿐이다.
9장은 캔버스·마커 위치를 **완전히 동일**하게 — 1:1로 갈아끼워야 물고기가 안 흔들린다.

## 지켜야 할 것

1. **`_guide.png`를 아래 레이어로 깔고 그린다.** 마지막에 가이드 레이어만 끄고 저장.
   캔버스는 가이드와 **1px도 다르면 안 된다.**

2. **`bg_source.png`엔 투명 픽셀이 하나도 없어야 한다.** 둥근 모서리 바깥도 어두운
   색으로 칠할 것 — 투명하면 바닐라 상자 배경이 그대로 비친다.

3. **소켓·제단을 배경판에 그리지 말 것.** 별도 파일로 받아서 우리가 정확한 좌표에
   합성한다. 배경판의 슬롯 영역은 **평평한 패널**로 비워둘 것.

4. **빨강 칸(플레이어 인벤) 영역엔 격자를 그리지 말 것.** 민무늬 패널로.

5. **제목 글자는 그림에 직접 그린다.** 마크가 제목을 따로 안 그린다.

6. 슬롯 영역 패널은 **저대비**로. 위에 아이템이 올라간다.

## 소켓 (96×96)

- 슬롯 칸은 72px인데 96px로 그리는 이유: 링이 칸 밖으로 나가야 두께가 나온다.
- **안쪽 64px 원형은 비워둘 것** — 거기 물고기가 앉는다.
- 이웃 소켓과 12px씩 겹친다. 사슬처럼 이어져 보이는 건 **의도한 것.**

## 제단 (420 × 300, 등급별 9장)

★**한 칸짜리 원형 제단이 아니라 5칸 폭 받침대다.** 낚시 결과는 물고기 한 마리가
아니라 더블/트리플 + 낚시 재료 + 보물상자까지 **한 번에 3~4개**가 나온다.
가이드의 **노란 상자(슬롯 11~15)** 를 덮는 가로로 긴 단상/제단으로 그릴 것.

- 상판이 가로로 **최소 384px**(5칸)을 덮어야 한다. 가이드 노란 상자 = x 160~543.
- 상판 **정중앙**(가이드 표시: x=351, y=176 자리)에 `#FF00FF` 순색 1px 십자 마커.
  스크립트가 그 점을 가운데 칸 중심에 맞추고 마커는 지운다.
- 소켓 5개가 상판 위에 얹히므로 **상판 윗면은 평평하고 저대비**로.
- 빛기둥·발광은 위로 번져도 됨(투명 레이어라 안전).

### 등급별 차이는 제단으로만
프레임까지 등급별로 바꾸면 화면이 요란해지고 수정 비용이 9배가 된다.
**빛기둥 색·강도·재질**로만 등급을 표현할 것 — 예: E는 흐릿한 회청색,
G는 강렬한 금색. 실루엣·크기·마커 위치는 9장 모두 동일하게 유지.

## 배경판 필수 좌표 (아트 px, 눈대중 금지)

가이드의 **주황 상자 = 프레임 침범 절대 금지.** 마크 슬롯 격자 위치는 고정이라
협상이 안 된다. 좌우 프레임은 **한쪽 16px 이내**로 얇게.

| 항목 | 값 |
|---|---|
| 슬롯 패널이 덮어야 할 범위 | x **16 ~ 688**, y **56 ~ 296** |
| 행 구분 헤어라인 | y = **140** 과 **212** (딱 이 두 값) |
| 나무 가로 구분 띠 | y **284 ~ 339** 안에 (이 구간을 벗어나면 안 됨) |
| 아래(인벤) 패널이 덮어야 할 범위 | x **28 ~ 675**, y **340 ~ 643** |

| 구역 | 그릴 것 |
|---|---|
| 상단 헤더 | 프레임 + "낚시 성공" 제목 |
| 청록 칸 3행 영역 | 평평한 패널. 행마다 재질을 달리해 역할 구분 |
| 청록/빨강 사이 띠 | 두 영역을 가르는 구분 띠 |
| 빨강 칸 영역 | 민무늬 |

3행의 역할 (소켓은 우리가 얹으므로 **패널 재질로만** 구분):
- 1행 = 부가 어획 · 2행 = 주인공(가운데 노란 칸) · 3행 = 정보칸(금속 명판 느낌)
