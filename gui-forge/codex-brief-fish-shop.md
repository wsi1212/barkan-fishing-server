# 발주 — 물고기 판매창 배경

첨부 3개: `src/fish_shop/_guide.png`(가이드 판) · `tree_bg_source.png`(스타일 레퍼런스) · 이 문서

낚시 성공 창과 **같은 세계관·같은 프레임**이어야 한다. 다만 그쪽은 "보상 공개"고
여긴 **유저가 물고기를 올려놓고 파는 좌판**이다 — 성격이 다르게 읽혀야 한다.

※ 낚시 창(704×672)보다 **한 행 크다.** 칸 구분선·버튼 아이콘은 우리가 코드로 얹으니 그리지 말 것.

## 지켜야 할 것

1. **`_guide.png`를 아래 레이어로 깔고 그린다.** 마지막에 가이드 레이어만 끄고 저장.
   캔버스는 **1px도 다르면 안 된다.**

2. **투명 픽셀이 하나도 없어야 한다.** 모서리 바깥도 어두운 색으로 — 투명하면
   바닐라 상자 배경이 그대로 비친다.

3. **주황 상자(FRAME MUST NOT ENTER) 안으로 프레임이 들어오면 안 된다.**
   좌우 프레임은 **한쪽 16px 이내**. 마크 슬롯 격자 위치는 고정이라 협상이 안 된다.

4. **빨강 칸(플레이어 인벤) 영역엔 격자를 그리지 말 것.** 민무늬 패널로.

5. ★**제목 글자를 그리지 말 것.** 제목은 게임 폰트로 실시간 출력한다
   (넣은 마리 수·합계 금액이 계속 바뀐다). 헤더는 **글자 없는 빈 명판**으로.

6. 좌판·버튼 자리는 **저대비**로. 위에 아이템이 올라간다.

## 구역 (가이드 참조)

| 구역 | 슬롯 | 그릴 것 |
|---|---|---|
| 헤더 띠 | 0~8 | 가로로 긴 **빈 명판**(글자 없음) + 양끝 장식 |
| **좌판** | 10~16, 19~25 (노랑) | **x 100~603, y 140~283** 을 덮는 움푹 팬 판매대 |
| 좌판 양옆 기둥 | 9, 17, 18, 26 | 좌판을 감싸는 테두리/기둥 — 아이템이 안 올라가는 자리다 |
| 조작 띠 | 27~35 | 아래쪽 버튼 바. **슬롯 31·35 자리에 버튼 홈 2개**를 파둘 것 |
| 인벤 영역 | — | 민무늬 |

## 좌판이 핵심
낚시 창은 "받침대 위 전리품"이지만 여긴 **생선을 늘어놓는 좌판**이다.
- 노란 영역 전체가 하나의 **연속된 움푹한 면**으로 읽혀야 한다.
  칸마다 홈을 파지 말 것 — 14칸 구분선은 우리가 정확한 격자에 얹는다.
- 가장자리에 낮은 턱을 둘러 "여기에 올려놓는 자리"임이 보이게.
- 젖은 나무·돌 좌판, 물기·비늘 자국 같은 생활감이 있으면 좋다.
- 헤더·조작 띠와는 **재질을 달리해** 작업면과 조작부가 구분되게.

## 구분선
헤더 / 좌판 / 조작 띠 / 인벤 사이에 **가로 구분선**을 넣어 층이 나뉘어 보이게 할 것.
가늘고 은은하게(청록 헤어라인 또는 얇은 금속 몰딩) — 굵으면 화면이 답답해진다.

## 스타일

검정에 가까운 짙은 남색, 포인트는 청록 발광. **어둡고 채도 낮게** — 물고기가 주인공.
