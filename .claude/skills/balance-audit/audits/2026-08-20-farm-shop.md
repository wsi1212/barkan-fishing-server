# 섬상점 농사 밸런스 감사 — 2026-08-20

## 요약 (TL;DR)

- 목표는 **32칸 농장 기준, 현재 낚시와 작살 중 낮은 기준인 낚시의 75%**다.
- 코호트 기준선: Lv1 최적 낚싯대 **84,930원/h**, 작살 **404,072원/h**.
- 목표 농장: **63,697원/h**. 추천 판매가 적용 후 작물별 32칸 수익은 **50,688~66,944원/h**,
  평균 **61,552원/h(낚시의 72.5%, 작살의 15.2%)**다.
- 작살은 낚시보다 4.76배 높아 농사를 두 콘텐츠 각각의 75%로 동시에 맞추는 것은 불가능하다.
  이번 운영안은 농사가 낚시를 넘지 않는 보수적 기준을 사용한다.

## 기준과 가정

| 항목 | 값 |
|---|---:|
| 비교 슬롯 | 32칸 |
| randomTickSpeed | 3 |
| 밭 상태 | 광원·수분 정상, 청크 상시 로드 |
| 재배 스킬 보너스 | 0% |
| 가격 배수 | 구매가 = 판매가 × 3 |
| 가격 기준 | `min(낚시, 작살) × 75%` |

바닐라 작물의 성장시간은 `CropSpecs.java`처럼 고정값이 아니다. 실제 random tick, 밭 배치, 청크 로딩에
따라 달라지므로 아래 cycle은 실측 전 운영 가정이다. `farm_shop_audit.py`에서 같은 가정을 다시 계산할
수 있고, telemetry 표본이 쌓이면 cycle만 교체해 가격을 재산출한다.

## 상점 연결·조합 검증

- 기존 가격표에 빠져 있던 `BEETROOT`, `MELON_SLICE`, `MELON`, `PUMPKIN`을 추가했다.
- `WHEAT` 9개 → `HAY_BLOCK` 1개의 판매총액을 동일하게 맞췄다(199×9 = 1,791원).
- `MELON_SLICE` 9개 → `MELON` 1개의 판매총액을 동일하게 맞췄다(111×9 = 999원).
- 구매가는 모든 농사 품목을 판매가의 3배로 맞춰 상점 구매 후 즉시 판매하는 차익을 막았다.
- 뼛가루는 자연 성장 우회 수단이라 `300원 구매/100원 판매`로 올렸다. 밀 1사이클을 뼛가루로
  즉시 밀어도 예상 산출가보다 비싸도록 한 것이다.
- 특수작물 수확물은 lore가 있는 아이템이고 `IslandShopGui.sell()`이 `hasItemMeta()`를 제외하므로,
  이번 바닐라 판매가가 특수작물 산출물을 직접 현금화하는 경로를 열지 않는다.

## 미확정 / 다음 실측

1. 일반 `FARMLAND`에는 특수작물 32칸 한도가 적용되지 않는다. 32칸 이상을 허용하면 총 농장수익이
   목표를 초과할 수 있으므로 일반 경작지 한도 또는 섬 면적 상한을 별도 결정해야 한다.
2. `OAK_SAPLING`, `APPLE`, `BONE`은 나무 성장·잎 드롭·몹 드롭 등 별도 생산 루프라 이번 9종 작물
   원/h 모델에 넣지 않았다. 현재는 편의/부산물 가격으로 유지했다.
3. 이번 변경으로 자연 성장으로 인정된 플레이어 파종 작물에
   `crop.harvest.vanilla.cycle(crop, grow_actual_s, tracked)` telemetry를 추가했다. 서버 재시작 전
   파종분은 `tracked=0`으로 분리하고, 충분한 신규 표본이 쌓이면 이 가정을 서버 실측으로 교체한다.
