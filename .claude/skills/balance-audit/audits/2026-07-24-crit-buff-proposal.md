> 최대기여 0.08→0.18. ②캡 폐지에도 크리가 여전히 최약체(특화빌드 +39%, 등급업은 캡폐지로
> +107%까지 뛰어 격차 오히려 확대)로 남아, 🅲안(직접 가격배수)을 **계수 0.06으로 튜닝해 적용**

> 0.18→**0.35~0.37**. 아래 원안의 🅰🅱는 캡 유지 전제였던 안이라 최종 미적용, 🅲의 방향은
> 채택하되 계수는 재산정(원안 0.12→최종 0.06, income대비 %가 아닌 종결투자 실측 기준 재조정).

## 문제 (측정)
완전 특화 빌드별 시간당 수입 증가 (시너지 반영, 무버프 32,489원/h 기준):

| 빌드 | 수입 증가 | |
|---|---|---|
| 판매 특화 (+110%) | +35,738 (+110%) | |
| 더블 특화 (+110%) | +35,738 (+110%) | |
| 크기 특화 (+100%) | +28,157 (+87%) | |
| 등급업 특화 (+40캡) | +24,720 (+76%) | |
| **크리 특화 (율50%·배율8, 현실)** | **+11,263 (+35%)** | ← 최약 |
| 크리 특화 (율80%·배율8, 이론최대) | +18,021 (+55%) | |

**크리는 다른 특화 빌드의 약 절반.** 게다가 크리는 크리확률+크리배율 **두 스탯을 동시에** 올려야
효과가 나는데(시너지=곱), 투자 대비 보상이 오히려 낮음.

## 근본 원인
크리는 `size += size×(critDmg×10%)` → quality → 가격 `0.5+q×0.5/100` 경로로만 작동.
이 가격 공식이 약해서(품질 +100이 가격 +33%뿐) 크리가 아무리 커도 가격에 잘 안 실림.
반면 판매/더블은 가격·물고기 수에 **직접** 작용. 또 **크리배율 캡 8**이 장비 잠재치를 낭비:
장비 크리배율(줄 최대5) + 강화(최대10) = **15까지 가능한데 8에서 잘림**(7포인트 사장).

## 수치안 (목표: 크리 특화 ≈ +65~75%, 등급업/크기 티어)

### 🅰 추천 — 크리배율 캡 8 → 15
- **변경**: `FishingListener.java` L309·L392 `Math.min(b.critDamage, 8)` → `Math.min(b.critDamage, 15)`
- **근거**: 이미 존재하는 장비+강화 투자(5+10=15)를 해금. 새 밸런스 상수 안 만들고 **사장된 캡만 정상화**.
- **결과**: 율50%·배율15 → **+21,118원/h (+65%)** = 등급업/크기 티어 진입.
- **부작용**: 크리 시 물고기 크기 최대 +150% → 경험치도 함께 상승(레벨링 보너스, 순기능). 품질 100 초과 빈번(가격 계속 상승, 의도 범위).

### 🅱 대안 — size 배수 ×10 → ×18
- **변경**: `FishingListener.java` L393 `critPct = critDmg * 10` → `* 18` (+ L311 표시 문구)
- **근거**: 크리배율 캡(8) 유지하되 크리 1회의 크기 증폭↑. 크리배율 스탯 스택 없이도 상향.
- **결과**: 율50%·배율8 → **+20,273원/h (+62%)**.
- **부작용**: 배율8에 크리 시 +144% 크기 = 시각적으로 과함. XP도 크게 상승.

### 🅲 대안 — 크리에 직접 가격배수 추가 (구조 개선)
- **변경**: 보상 경로에서 크리 시 판매가 `× (1 + critDmg×0.12)` 적용(현재 `critMult`가 낚시 크리엔
  1.0로 사장됨 — `calcPrice`에 실제 critMult 전달하도록 배선). size 경로는 XP/연출용으로 유지.
- **근거**: "크리티컬 = 대박 한 방" 판타지에 부합. XP는 이미 `critExpMult=1+critDmg×0.1` 직접배수라 **일관성↑**. 약한 size→가격 공식 우회.
- **결과**: 율50%·배율8 → size분(11,263) + 가격분(15,595) = **+26,858원/h (+83%)**. ★가장 강함, 세밀 튜닝(0.12) 필요.
- **부작용**: 새 배선(price path). 이론최대(율80%)에서 +132%로 판매(+110%) 초과 → 계수 0.12→0.08 하향 조정 필요.

## 권고
**🅰(캡 8→15)** 우선 — 최소 변경, 사장 투자 해금, 목표치 명중, 부작용 순기능(레벨링).
크리를 "대박 한 방" 컨셉으로 재설계할 의향이면 **🅲**가 구조적으로 가장 깔끔(단 튜닝·배선 필요).
