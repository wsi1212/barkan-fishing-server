# 밸런스 감사 후속 — 2026-08-22 발효케이크 재료 배분

## 결론

`발효케이크`의 중간재 도입은 기존 원재료를 대체하지 않고 추가하는 방식으로 확정했다.

```text
발효케이크
├─ 따뜻한 빵 x3
├─ 특수 토마토 x26
├─ 강화 밀 x6
└─ 강화 당근 x2
```

이전 조정안의 `특수 토마토 20 + 강화 밀 4 + 강화 당근 1`은 농사 재료 수요를 줄였기 때문에 폐기했다. 현재 수량은 중간재를 추가하기 전 기존 레시피의 `26/6/2`를 그대로 복원한 값이다.

## 기회비용 환산

`따뜻한 빵` 1개는 `특수 밀 2 + 강화 밀 4`를 소비한다. 따라서 `발효케이크` 1개에 필요한 직접·하위 재료는 다음과 같다.

| 재료 | 직접 수량 | 따뜻한 빵 3개 하위 수량 | 총 수량 |
|---|---:|---:|---:|
| 특수 토마토 | 26 | 0 | 26 |
| 특수 밀 | 0 | 6 | 6 |
| 강화 밀 | 6 | 12 | 18 |
| 강화 당근 | 2 | 0 | 2 |

따라서 농사 재료 수요는 이전 조정안보다 `특수 토마토 +6`, `강화 밀 +2`, `강화 당근 +1` 늘었고, 빵의 하위 재료인 `특수 밀·강화 밀`도 새로 명시적인 소비처를 갖는다. 발효케이크 자체에는 기존 레시피에도 채집물이 없었으므로, 임의의 채집물을 추가해 원래 생산 경로를 바꾸지는 않았다.

## 밸런스 판정

- 🟢 농사 원재료 보존: 기존 `26/6/2`를 유지해 상위 요리가 농사 수요를 잠식하지 않는다.
- 🟢 중간재 의미: 따뜻한 빵 3개가 별도 제작·소비되므로 하급 요리 제작 루프가 생긴다.
- 🟡 생산량 확인 필요: `특수 밀`, `강화 밀`, `특수 토마토`, `강화 당근`의 실제 생산량과 재고 소진 속도는 서버 재시작 후 telemetry로 확인한다.
- 🟡 채집 경제: 발효케이크에는 기존에도 채집 원재료가 없었으므로 이번 조정에서 채집물을 새로 배정하지 않았다. 다른 채집 기반 상위 요리의 재료가 줄어들지 않았는지는 전체 요리 audit의 기존 체인 검사를 기준으로 유지한다.
