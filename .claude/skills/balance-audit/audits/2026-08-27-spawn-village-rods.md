# 밸런스 감사 — 2026-08-27 · 스폰마을 낚싯대 전수 (레벨제한 · 재료 · 성능)

## 요약 (TL;DR)
- 종합 상태: 🔴 — **등급도 레벨제한도 가성비를 예측하지 못한다.** 가성비를 결정하는 건 «라인(주력
  스탯)»이고, 채집(재확) 라인이 다른 전 라인을 앞선다. 미끼에서 지적된 것과 **같은 구조 문제**다.
- 총비용의 **중위 80%가 재료**다(60~100%). 즉 「재료 대비」가 사실상 「비용 대비」의 전부다.
- 병목 재료가 **강화실 11종 · 낚은갈고리 7종**에 집중 — 24종 중 18종이 이 둘 중 하나로 막힌다.
- 조치 권고: 🔴 3 · 🟡 3

## 대상 · 모델
스폰마을 출처 낚싯대 **30종**(구매가능 24 + 히든 6). `item_ledger.py` 원장:
```
총비용   = 돈가격 + 재료게이트(h) × 그 레벨 구간의 실측 시급
순성능   = income + 성장(경험치) + 게이트(재료확률) + 내구보존 절감 − 자기 유지비
회수시간 = 총비용 ÷ 순성능      (성능 1원/h 을 사는 데 드는 지불액)
```
실측: 포획 190.1/h · 소모 194.0/h · 크기점수 69.3 · 시급 Lv1-9 76,493 / Lv10-19 99,645 /
Lv20-29 115,083원/h (`measured.py`, 2026-08-26 스냅샷).
재료 게이트는 LP 쌍대해(`material_value.py`) — 결합생산·다지역·광질 반영.

★**이번 감사 중 모델 결함 1건 수정**: 낚싯대의 **경험치를 성능에 넣지 않고 있었다**(릴·미끼만
포함). 그래서 경험의 낚싯대가 19.5h(최악)로 잡혔는데 성장을 넣으면 8.4h(상위권)다. `stat_value`
의 경험치 값 자체가 「레벨링 국면: income 1%와 동가치」로 정의돼 있어 카테고리별로 넣고 빼면
일관성이 깨진다 → **전 카테고리 포함**으로 바꿨다. 단 이 값은 **만렙 후 0** 이므로
`growth_share` 컬럼으로 비중을 드러낸다.

## 조치 권고 (우선순위)

1. **[🔴] 재확 라인을 낚싯대에서도 정리할 것.** 채집용(재확 10)·수집가의(18)·탐사자의(28)·
   탐구자의(50)가 각각 등급 내 최고 가성비다. 미끼에서 «재료확률 전문 미끼»로 분리한 것과 같은
   처방이 필요하다 — 지금은 재확 라인이 «다른 라인 + 재확»이라 그냥 상위 호환이다.
   (미끼는 수입축을 뺐다. 낚싯대도 같은 방향이면 일관된다.)
2. **[🔴] 초보 낚싯대(Lv1, 50원) 재설계.** 재료 31,185원어치를 요구하면서 성능이 1,223원/h 다.
   실사용 765회로 신규 유저가 실제로 걸린다. 재료를 줄이거나(0.41h → 0.1h) 스탯을 올릴 것.
3. **[🔴] Lv10 두 종(낚시꾼의·잉어꾼의) 재설계.** 15.0h·18.2h 로 Lv5~9 전부보다 나쁘다.
   레벨을 올려 새 낚싯대를 사는 순간 손해 보는 구간이 Lv10 이다.
4. **[🟡] 크리·등급업 라인 부여량 상향.** 크리확률 0.48 · 크기 0.60 은 하위 스탯인데 그것만
   주는 라인이라 일관되게 최하위다. 등급업은 정규화 2.11(최고)인데 부여량이 1~4 로 작아
   가격을 못 정당화한다 — 라인의 정체성을 살리려면 부여량을 올려야 한다.
5. **[🟡] B 등급 구간 가격 인하.** B 중위 12.1h 가 C 8.7h 보다 나쁘다. 재료 비중이 70~81% 이므로
   가격보다 **재료 소요량**을 줄이는 쪽이 효과가 크다.
6. **[🟡] 행운의구슬 병목 재검토.** 스폰마을 낚싯대 4종이 실측 조업 비중 1.2%/0% 지역(정상·
   붉은사막) 재료로 막혀 있다. 초반 마을 레시피는 강/항구에서 닫히는 게 설계 원칙이었다
   (`gen_part_builds.py` 2026-08-23 주석) — 낚싯대 쪽엔 그 원칙이 적용되지 않았다.
