# 이무기 보스 — 여의주 신설 (2026-07-25, 실제 구현)

## 배경
낚시 감사에서 계속 "용비늘=이무기 보스 드랍, 파밍 불가"로만 인용하고 정작 **보스 전투 자체의
난이도/보상 밸런스는 이번 세션에서 감사한 적 없음**(SKILL.md 확장 논의 중 스스로 지적한 공백).
사용자 지시: 이무기 처치 시 특별한 재료 지급, 용도는 나중에 정함(향후 콘텐츠 대비).

## 구현
`ImugiBattle.dropReward()`에 **여의주** 신설 — 기존 용비늘(35%)과 독립적인 20% 확률 롤.
- 명명: "이무기=아직 용이 되지 못한 존재"라는 한국 설화 모티프 → 용이 되면 얻는다는 여의주로
  명명, "용도 미상"이라는 아이템 설명과 서사적으로 자연스럽게 맞물림.
- `materials.json`에 신규 등록(`mcItem=nether_star` — 용비늘의 `dragon_breath`와 안 겹치게 선택).
- 두 드롭은 서로 독립(같은 처치에서 용비늘+여의주 둘 다 나올 수도, 하나만, 둘 다 안 나올 수도 있음).
- `crafting.giveMaterial()` 재사용(도감/퀘스트 훅 자동 연동, 기존 용비늘 지급 패턴과 동일).

## 파일 변경
- `blockship-plugin`: `boss/ImugiBattle.java` `dropReward()` 수정. 커밋 `71af70f`.
- `plugins/BlockShip/materials.json` — `여의주` 신규 등록. 백업 `materials.json.bak-20260725-yeouiju`.

## ★남은 작업 (사용자가 "용도 미정"이라 했으므로 지금은 보류)
- 여의주를 실제로 어디에 쓸지 결정 필요 — 후보: 초-엔드게임 장비(현재 최고티어 S급 낚싯대 위의
  새 등급), 강화 +21 이후 확장, 아니면 완전히 다른 시스템(스킬트리 궁극기, 진화형 부품 등).
- **보스 전투 자체(난이도·시간·HP·페이즈)의 밸런스 감사는 아직 미완료** — 원래 요청("이무기 보스
  전체 감사")의 절반(재료 신설)만 완료. 전투 밸런스(처치 소요시간 대비 보상 가치, 페이즈 난이도
  곡선)를 이어서 볼지는 후속 결정 필요.

## 배포 필요
JSON(materials.json)은 재빌드 불필요, Java 변경(ImugiBattle.java)은 빌드+배포+재시작 필요.
아직 미배포 — 다른 미배포 변경들(주문서 조합, 통발 수정 등)과 함께 모아서 처리 권장.
