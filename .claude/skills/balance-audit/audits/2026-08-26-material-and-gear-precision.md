## I. 재료 가치 — 구 모델은 세 겹으로 틀렸다

### 무엇이 틀렸나
1. **결합생산 무시.** `CraftingManager.rollMaterials` 는 그 지역 드롭테이블 **전체를 순회하며 각각

   시간을 여러 번 센다.
2. **다지역 무시.** 실측 materials.json 20종 중 **진주 8%·별빛진주 2% 는 16개 지역 전부**에
   있다. 물고기비늘 10곳, 강화실 8곳. 지역 전용은 오아시스 7종과 날씨 1종뿐.
   ⇒ 2026-08-26 오전 감사의 「별빛진주는 협곡 전용 병목, 그래서 고티어 게이트를 4배 과소평가」
   판정은 **틀렸다.** 별빛진주는 어디서 낚아도 나온다.
3. **광질 재료를 0원으로 버렸다.** 장비 레시피 재료 슬롯 1,187개의 사용 빈도:
   진주 194 · **강철심 175** · **압축흑정석 163** · **단단한자루 125** · **강화철괴 91** ·
   정제된갈고리 69 · 별빛진주 54. base 까지 전개하면
   `강철심 = 석탄64 + 철주괴32 + 녹슨부품8`, `압축흑정석 = 흑정석9`, `바르칸핵 = 흑정석36 + …`.
   구 `material_gate.py` 는 이걸 `("item", …)` 버킷에 담고 게이트 계산에서 제외했다.

### 새 모델
```
min Σ_A h_A   s.t. Σ_A h_A · r[A][m] ≥ q[m],  h ≥ 0        (A = 지역별 낚시 / 섬광산 / 드릴)
λ[m] = 쌍대변수 = 재료 1개의 시간가격(h/개)
```
성질: 다지역 재료는 최저비용 경로로 자동 평가 · **병목이 아닌 재료는 λ=0**(공짜 부산물) ·
`Σ λ·q = 총 게이트`. 원 환산은 마지막에 딱 한 번 실측 시급으로.
구현: 의존성 0 표준 심플렉스(`material_value.py:simplex_max`).
