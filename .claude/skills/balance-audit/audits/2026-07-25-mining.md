# 광질(mining) 감사 — 2026-07-25 (베이스라인)

## 요약 (TL;DR)
- 종합 상태: 🔴 **치명 후보 1건 발견** (섬 광산 처리량 무제한) · 나머지는 🟢.
- 첫 감사 — 델타 없음. 이 스냅샷이 향후 비교 기준.
- 광질은 낚시와 근본 구조가 다르다: **순수 소모(money) + 재료생산**, 직접 판매경로 없음(확인:
  `SellCommand`/`SellGuiListener` 무관련).
- **두 시스템은 완전히 별개**(사용자 확인): 섬 광산(island_world/guild_world, 바닐라 마크 광석 —
  돌/석탄/철/구리/금/청금석/다이아/에메랄드) vs 드릴 시스템(mine월드/레드_로드, 흑정석/자수정 전용).

## A. 드릴 채굴 (mine월드/레드_로드)  🟢
| 항목 | 값 |
|---|---|
| 티어 | T1(배속1.0, 3,000원 직구) → T2(배속2.0, 레시피해금 10,000원+Lv15, 압축흑정석8) → T3(배속3.5, 레시피해금 30,000원+Lv30, 압축흑정석16+자수정8) |
| 흑정석계 (mine월드) | 얇은(30틱/180s재생/1개) · 보통(50틱/300s/1~2개) · 풍부한(80틱/480s/1~3개) |
| 자수정계 (레드_로드) | 얇은(40틱/180s/1개) · 보통(60틱/300s/1~2개) · 정동(90틱/480s/1~3개) · 군집(70틱/360s/1~2개) |
| XP | breakTicks÷2 (15/25/40, 자수정 20/30/45/35). **일일캡 없음** |

- **자연 제약 존재**: 파괴시간(T1 기준 1.5~4.5초, T3면 0.43~2.57초)+재생 180~480초. 낚시의
  "미니게임 게이팅"과 유사한 역할 — 시간이 지나야 다시 캘 수 있다. 🟢 설계 의도대로.
  단, **실제 시간당 처리량은 채굴존 광맥 개수(서버 빌드 데이터, 코드에 없음)에 좌우** — 이 수는
  현장 확인 없이 추정 금지(metrics.md 명시).
  - ⚪ **압축흑정석 순환참조**: T2/T3 레시피 자체가 압축흑정석(=흑정석9개 조합)을 요구 →
    T1으로 먼저 캐야 T2/T3를 만들 수 있는 자연스러운 순차 진행. 버그 아님, 설계 확인.
- **직접 판매경로 없음** — 흑정석/자수정은 순수 크래프팅 인풋(압축흑정석·부품 레시피).

## B. 섬 광산 생성기 (island_world/guild_world)  🔴
| 항목 | 값 |
|---|---|
| 메커니즘 | 물[공백1~8칸][울타리] → 공백에 광석 자동생성 → 채굴 → 드롭+**즉시 재생**(쿨타임 0) |
| 광석 확률(가중치100 기준) | 돌35% · 석탄19% · 철15% · 구리11%(2~4개) · 금6% · 청금석4%(4~8개) · 다이아5% · 에메랄드5% |
| XP 일일캡 | 500회(`ISLAND_MINE_DAILY_CAP`) — **아이템 드롭은 캡 이후도 무제한** |

- 🔴 **처리량 서버측 상한이 전혀 없음.** `IslandMineListener.onBreak`이 `BlockBreakEvent`를 가로채
  드롭만 대체하고 **바닐라 파괴속도는 그대로 통과**시킨다(코드 확인: 속도 override 없음, 즉시재생만
  플러그인이 처리). 즉 실제 처리량은 **플레이어의 바닐라 곡괭이 티어에 정비례** — 네더라이트+효율5+
  헤이스트 조합이면 블록당 사실상 즉시파괴. 낚시(미니게임)·드릴(내구도+재생)과 달리 **파밍 속도에
  아무 제동이 없다.**
  - 엔드게임 장비 유저가 섬 광산 하나를 캠핑하면 다이아몬드/에메랄드(각 5%, XP10)까지 사실상
    무제한 획득 가능. 매크로/자동클릭 도구와 결합 시 리스크 배가.
  - **일일 500회 XP캡은 이 문제를 안 막는다** — 캡은 스킬 경험치만 멈추고 아이템 획득은 계속됨
    (코드 확인: `if (n>=CAP) return;`이 XP 함수 안에만 있고 드롭 로직과 분리).
  - 권고: 블록당 최소 쿨타임(예: 0.3~0.5초 서버측 강제) 또는 **아이템에도** 일일 캡 도입.

## 드리프트 (코드 vs balance.md)

  광질 밸런스의 **최초 문서화**.

## 조치 권고 (우선순위 순)
1. **[🔴] 섬 광산 처리량 무제한** — 블록당 서버측 쿨타임 신설(예: 0.3~0.5초) 또는 아이템 일일 캡
   도입. 현재는 바닐라 도구 티어에 그대로 스케일돼 엔드게임 유저에게 사실상 무한 자원.
2. **[🟢 확인] 드릴 자연 게이팅은 정상** — 손댈 필요 없음. 단, 채굴존 광맥 밀도(레이아웃)를
   현장에서 확인해 실제 시간당 처리량 추정치를 다음 감사에 추가할 것(코드만으론 알 수 없음).
3. **[정보] 낚싯대/부품 레시피 재료 중 압축흑정석(순수 드릴)·강화다이아몬드/금괴/에메랄드(섬광산
   원석 압축)가 있음** — 위 🔴가 해소 안 되면 이 재료들의 "진짜 비용"이 사실상 0에 가까워
   장비가격 감사(H절)의 재료비 가정이 무의미해진다. 🔴 조치가 먼저.
