# 통발(trap) 감사 — 2026-07-25

## 요약 (TL;DR)
- 종합 상태: 🟢 양호 (1건 발견·즉시 수정 완료: 붉은사막 가격-성능 역전)
- 구조 자체는 매우 안전 — 플레이어당 설치 1개 제한(`TRAP_LIMIT=1`), 내구도 소모품, 능동 재배치
  필요(6~15분 대기). 섬광산과 달리 "무제한 처리량" 리스크 패턴 없음.
- ★핵심 방법론 교훈: **데이터에 있다 ≠ 실제로 존재한다.** 12개 통발지역 중 절반(늪지대·붉은호수·
  대양·물보라동굴·깊은호수)이 regions.json에 좌표 `[0,0,0]` 스텁이고, 원양어선은 아예 미등록.
  실제 라이브 지역은 **6개뿐**(스폰도시·강·오아시스·강_상류·붉은사막·정상).

## A. 메커니즘 (`trap/TrapManager.java`, `trap/TrapSpecs.java`)
- 설치: SHIFT+우클릭, 해당 지역 물 근처만. 회수: SHIFT+좌클릭.
- `TRAP_LIMIT=1` — 플레이어당 동시 설치 1개. 틱 주기 30초(`runTaskTimer(600,600)`), 지역별
  `waitSec`(360~900초) 경과 시 "완료" 표시, 플레이어가 직접 회수해야 물고기 지급.
- 내구도(`maxDur`, 4~12) — 회수 1회당 -1, 0 되면 파괴(반환 없음). 대기 취소는 내구 유지.
- 산출: 지역별 "통발" 전용 어종 풀(fish.json)에서 **등급가중치**(E100:D80:C55:B32:A16:S8:M4:L2:G1,
  `TrapManager.gradeWeight` — ★정상 낚시 PRD 확률과 무관한 별도 체계, 좁은 풀에선 왜곡 큼)로 1~2마리
  (70%:1마리/30%:2마리) 추첨. 품질은 균등분포 10~60(평균35, 정상낚시 기본50보다 낮음).
- 레시피: 마을 상점에서 해금(2,000~45,000원) → 조합대 제작(바닐라 재료: 끈·대나무·조약돌 등, 저렴).

## B. 지역 존재 여부 전수검증 (regions.json 대조)  ★신규 방법론
| 지역 | regions.json 상태 |
|---|---|
| 스폰도시·강·오아시스·강_상류·붉은사막·정상 | ✅ 실존(좌표 있음) |
| 늪지대·붉은호수·대양·물보라동굴·깊은호수 | ⚪ 스텁(pos1=pos2=[0,0,0]) — 미구현 |
| 원양어선 | ⚪ regions.json에 아예 없음 |

스텁 지역들의 레시피(TR05/08/10/11/12/13, 9,000~45,000원)는 **상점에서 구매 가능하나 설치 불가능**
(nearWater+region 매칭이 좌표 [0,0,0]에서 항상 실패) — 유저가 못 쓰는 아이템에 돈만 날리는 구조.
★조치 권고 별도 항목(아래).

## C. 실존 6개 지역 가격-성능 곡선  ✅ (1건 발견·수정)
| 지역 | 레시피비 | 원/h(수정전) | 원/h(수정후) |
|---|---|---|---|
| 스폰도시 | 2,000원 | 1,462 | 1,462 |
| 강 | 5,000원 | 3,949 | 3,949 |
| 오아시스 | 6,000원 | 7,338 | 7,338 |
| 강_상류 | 10,000원 | 11,700 | 11,700 |
| **붉은사막** | **12,000원** | **1,316 🔴역전** | **14,742 ✅수정** |
| 정상 | 16,000원 | 17,550 | 17,550 |

- 🔴→✅ **붉은사막 가격-성능 역전 발견 및 수정.** 통발풀이 "크라운로치"(D등급) 1종뿐이라 레시피
  5위(12,000원)인데 성능은 꼴찌(스폰도시보다도 낮음)였음. 게다가 크라운로치는 붉은사막 "기본"
  낚시풀과 중복 등재(다른 지역은 전부 통발전용 별도 어종, 이 지역만 예외였음).
- **수정**: 통발전용 신규어종 3종 추가(`적사막게`B, `모래장어`B, `황금모래왕장어`A), 크라운로치는
  통발목록에서만 제거(기본 낚시풀엔 그대로 유지 — 일반 낚시 유저에 영향 없음 확인).
  결과 14,742원/h — 6개 지역 전체가 이제 **레시피가격 순 단조증가**(2,000→16,000원 = 1,462→17,550원/h).
- 정상 낚시(32,489원/h) 대비: 통발 최고(정상 17,550원/h)도 절반 수준 — "보조 수입원" 포지션 적절.
