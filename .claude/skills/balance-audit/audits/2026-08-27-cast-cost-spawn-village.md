# 요구 캐스트 재조정 — 스폰마을 (2026-08-27)

> 유저: "지금 평균 장비를 만들기 위해 몇 캐스트가 필요한지 구하고 그거 재료 요구 개수를
> 수정하는 작업 해줘. 밸런스 망가지지 않게. 같은 등급이라도 성능차이에 따라 10~25%까지
> 차이나게 요구캐스트. 일단 스폰마을부터"

권위: `scripts/cast_cost.py` (목표 산출) · `fish-tools/patch_cast_cost.py` (정수 수량 적합)

## 0. 「캐스트」의 정의

    캐스트 = LP 재료게이트(h) × 실측 249.1 캐스트/h

재료 게이트는 여태 **시간**으로만 나왔다(`material_value.py` 의 LP 쌍대해). 시간은 활동을
섞어 비교할 때 옳지만 플레이어의 단위가 아니다. 드롭은 캐스트→포획마다 굴러가므로
캐스트는 재료 요구 수량과 **1차 동차**로 직결된다 — 그래서 조정 손잡이로도 캐스트가 맞다.
광질·바닐라가 섞인 구간은 같은 환율로 환산한 «낚시 등가 캐스트»다(낚싯대 A급 최대 12%).

## 1. 착수 시점의 진단 — 요구 캐스트가 성능을 전혀 안 보고 있었다

같은 등급 안에서 요구 캐스트가 **거의 상수**였다. 레시피가 복붙으로 늘어난 흔적이다
(떡밥과 면줄은 재료가 글자까지 같았다):

| 그룹 | 요구 캐스트 | 순성능 산포 |
|---|---|---|
| D 낚싯대 6종 | 전부 **393** | 9,245 ~ 11,799 (+28%) |
| C 작살 5종 | 전부 **382** | 47,755 ~ 57,803 (+21%) |
| B 부품 (릴·줄·바늘·찌) | 580 ~ 626 | 8,413 ~ 65,669 (**+681%**) |

B 슬롯이 극단이다 — 카본줄(8,413원/h)과 전술 릴(65,669원/h)이 **같은 재료비**였다.

## 2. 목표 모델

    요구캐스트(item) = κ(카테고리, 등급) × 순성능(item)

κ = 「순성능 1,000원/h 당 캐스트」 = **캐스트로 잰 회수시간**. κ 가 그룹 안에서 상수면
요구캐스트가 성능에 정확히 비례한다 = 유저가 말한 «성능차이만큼 요구캐스트 차이».

κ 는 손으로 정하지 않는다. 현재 (카테고리, 등급) 중앙값에 대한 **단조감소 등위회귀(PAVA)**
로 낸다 — 「지금 값에서 최소한으로만 움직이되 단조성만 강제」. 단조감소를 거는 근거는
유저 기존 원칙 「상위 등급은 가성비가 좋아야」(`feedback_tier_value_must_improve`).
마지막에 **카테고리 총량 보존 배수**를 곱한다 → «밸런스 망가지지 않게»가 수식으로 보장된다.

카테고리를 따로 정규화하는 이유: 작살 성능은 «무료 나무작살 대비 증분»이라 낚싯대와
스케일이 다르다(C급 작살 57,803 vs C급 낚싯대 16,548 원/h). 한 κ 로 묶으면 작살 재료비가
3.5배로 뛴다.

**E 급은 사다리 밖**(튜토). 초보자 찌 26원/h · 녹슨 릴 −321원/h 처럼 성능 모델이 잡음이라
κ 를 뽑으면 찌 E 가 568(= D 의 32배)이 되어 등위회귀 전체를 왜곡한다.

## 3. 폐기한 설계 — 동레벨 대칭 수축

처음엔 동레벨 산포가 25% 를 넘으면 기하평균 쪽으로 대칭 수축했다. **멀쩡한 종이 같이
끌려갔다**: 쇠날 작살이 43,532원/h(같은 Lv6 평균의 3배)라는 이유로 벼린 작살(14,682, 정상)의
목표가 303 → 450(**+48%**)으로 밀렸다. 이상치의 죄를 옆 아이템이 뒤집어쓰는 구조다.

반대로 이상치를 성능만큼 비싸게 매기는 것도 안 된다 — 쇠날 작살이 851 캐스트가 되어
**모든 C 급 작살(382)보다 비싸진다**(D 급 κ 가 C 급의 3배라 성능이 조금만 튀어도 등급 역전).

→ 결론: **이상치는 스탯을 먼저 고쳐야 한다. 재료로 덮지 않는다.** hold 로 표시하고 제외.

## 4. 정수 수량 적합

LP 는 수요벡터에 1차 동차라 «전 재료 s 배»가 수학적으로 정확한 해다. 오차는 오직
**정수 반올림**에서만 온다 — 그런데 수량이 1~8 이라 균등 반올림만 하면 중앙 +6.7%, 최악 +84%.

  1. 균등 배율 반올림을 출발점으로
  2. ±1 좌표하강 (목적 = |ln(캐스트/목표)| + 0.05 × Σ|ln(q/균등q)|)
     — **모양 벌점**이 없으면 「병목 재료 하나만 8→1」 같은 해로 간다. 캐스트는 맞지만
       레시피 정체성과 GUI 가독성이 망가진다.
  3. 그래도 8% 를 못 맞추면 **중간재 되돌리기** — 정제된갈고리 1 개 = 낡은갈고리 8 개
     = **146 캐스트** 라 정수 격자가 성글다. 되돌리면 격자가 8 배 잘아진다(요구 총량 동일).
     · 되돌림은 **E·D 등급만** — C 이상에서 「정제된」을 「낡은」으로 바꾸면 등급이 내려간 느낌.
     · **단단한자루(강화실12+물고기비늘16)는 일부러 뺐다** — 되돌리면 「자루 없는 작살」이
       되고 물고기비늘이 33 개까지 불어난다. 정체성이 정확도보다 앞선다.

결과 오차: **중앙 1.1% · 90분위 4.6% · 최악 8.9%** (109종). 중간재 되돌림 9건.

## 6. 남은 문제 (이번 작업 범위 밖)

**(a) 부품 4슬롯의 κ 가 등급 간 평평하다** — 줄 44.0/43.4/43.2 처럼 D·C·B 가 사실상 같다.
낚싯대(37.7→10.4)·작살(20.7→6.5)은 등급마다 가성비가 좋아지는데 부품만 그렇지 않다.
부품 사다리는 대체로 «같은 스탯 큰 숫자»라 유저 원칙상 단가가 내려가야 한다.
고치려면 D 부품을 비싸게 / B 부품을 싸게 해야 하는데, 이건 «등급 가격 정책» 결정이라
이번의 «성능 비례 재분배»와 성격이 다르다 — 별도 결정 필요.

**(b) 동레벨 성능 이상치 4쌍** — 재료가 아니라 스탯 사다리 결함:

| 그룹 | 성능 격차 | 내용 |
|---|---:|---|
| 작살 Lv6 | +197% | 쇠날 작살 43,532 vs 벼린 작살 14,682 (**hold — 재료 미변경**) |
| 릴 Lv19 | +47% | 철제 릴 29,323 vs 황동 릴 19,975 |
| 낚싯대 Lv60 | +41% | 탐구자 196,226 vs 전승자 139,320 |
| 미끼 Lv20 | +31% | 번개 13,650 vs 반딧불이 10,454 |

**(c) 정수 격자로 못 닿은 3종** — 강철심(다중 원재료라 되돌릴 수 없음)이 큰 덩어리:
떡밥 +9% · 빛나는 미끼 +9% · 물때 작살 +15%.

**(d) 미끼 원장 모델 결함(기존 백로그)** — 자기유지비(캐스트/h × 판매가)가 보너스를 넘어
전 미끼의 순성능이 음수다. 그건 **가격** 문제라 여기서는 총성능(eff)으로 순위를 매겼다.

## 7. 회귀 방어

`selftest.py [9] 요구 캐스트 계약` 신설 — ① 요구캐스트 ↔ 성능 비례(목표 대비 ±15%)
② κ 등급 단조(상위 등급 가성비 역전 금지) ③ 동레벨 성능 이상치(경고).
레시피를 손으로 고치면 여기서 잡힌다.
