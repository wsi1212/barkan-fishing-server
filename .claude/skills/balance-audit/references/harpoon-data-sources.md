### ★가장 중요한 정정 — 「작살 저평가」 판정의 전제가 실측으로 무너졌다
`gear_payback.py` 는 «작살 270 포획/h vs 낚싯대 220» 을 근거로 **처리량 ×1.23**, quality 포함
**×1.43 income 우위**라 적고 「작살 55종의 가격이 낚싯대와 같은 밴드인 것은 작살 저평가」라고
결론했다. 실측은 정반대다:

- 처리량이 **낮다** (174.8 < 190.1). 창은 스폰을 기다리고 32% 만 잡는다.
- quality 우위(×1.089)가 처리량 열위(×0.920)를 겨우 상쇄해 **income 비 = ×1.001**.
- 즉 작살의 실제 우위는 **처리량도 income 도 아니라 «한계비용 0»** 하나다.
  낚싯대의 유지비(A 등급 4슬롯 수리 194×39×4 = 30,264원/h + 미끼)를 작살은 내지 않는다.

⇒ 08-03 권고(「quality 를 실제 크기 백분위로, 유지비 도입」)의 **quality 부분은 여전히 유효**하지만
(70~100 균등은 낚싯대 실측 69.3 대비 명백한 우대), **처리량 프리미엄을 근거로 한 가격 인상 논의는
폐기**해야 한다. 실측상 작살은 income 이 낚싯대와 같다.

## 창 전용 스탯 가치 모델 (`harpoon_value.py`, 2026-08-26 신설 · 실측 16/16 검증)

**해결됐다.** 초안 상태(«모델 없음 → 55종 중 37종 판정 불가»)는 해소됐고, 이제 `item_ledger.py`
의 모델 커버리지가 **100%** 다(야간투시만 미모델링이나 3종에서 부수 스탯이라 게이트에 안 걸린다).

### 모델의 뼈대 — 전부 라이브 코드에서 가져왔다
```
체력      HP(g,size) = base[g] + floor(max(0,size-100)/50)   base = E1 D2 C3 B5 A8 S12 M18 L25 G35
찌르기    피해 = 공격력,      간격 = max(2, round(5/(1+공격속도/100))) 틱
★돌진    피해 = 공격력 × 2,  쿨타임 = max(20, round(200/(1+돌진쿨감/100))) 틱
제한시간  W = max(20, round(base_w[g] × (1 + min(0.50, 도망감소/100)))) 틱
          base_w = E140 D140 C140 B130 A120 S120 M130 L160 G200
포획성립  타이머는 첫 명중에 시작하고 갱신되지 않는다 ⇒ jabs × 조준간격 ≤ W
사이클    t_search(잔차) + t_approach(수영속도) + t_engage(jabs) + t_surface(수중호흡·호흡시간)
income/h  (3600/cycle) × Σ_g P(g) × P(포획|g) × price(g) × quality배율
```

### ★검증에서 배운 것 두 가지 (둘 다 초안 모델을 반박했다)
1. **돌진은 이동수단이 아니라 «2배 피해 공격»이다.** `HarpoonManager:1420` 의
   `sweepAttack(..., max(1, getAttackPower(p)*2))`. 초안은 이걸 빼서 «철 작살(공2)로 S(HP12)
   포획»을 불가로 판정했는데, 실측은 5 명중으로 1 포획이었다(찌르기만이면 6번 필요).
   돌진 4 + 찌르기 4×2 = 12 로 정확히 맞는다. ⇒ **돌진쿨감은 교전 DPS 스탯**이고, 쿨타임
   200틱(10초)이 제한시간(6~7초)보다 길어 기본은 교전당 1회지만 **43% 부터 2회**가 들어간다.
2. **빗맞힘 차감을 자동 적용하면 안 된다.** 실측 명중률이 18% 라 상한(−34%)을 걸었더니 실제
   포획을 «불가»로 판정했다. 실제 A 교전 로그가 «+1.40 / +2.60 / +1.35»(5.35초)로 성립했는데
   그건 −34% 적용치(3.96초)를 넘는다. `harpoon.miss`(grade 빈칸 = 허공 스윙)는 교전 타이머를
   깎는 그 빗맞힘이 아니다.

- **공격력은 계단이다** — 위 값은 대표 빌드에서의 국소 미분이라 천장 바로 아래에서는 훨씬 크고
  천장 위에서는 0 에 가깝다. 사다리 설계에서 실제로 중요한 것은 이 미분값이 아니라 위 천장표다.
- **공격속도 = 0 은 모델 결론이지 버그가 아니다.** `JAB_GAP_TICKS = 5`(0.25초)를 줄이는 스탯인데
  실측 조준간격이 1.30초다 — 병목이 쿨타임이 아니라 조준이다. 실측이 방향까지 보여준다:
  공격속도 18 인 강철 작살의 명중간격 중위 1.55초 > 공격속도 0 인 나무 작살 1.00초.
  살리려면 JAB_GAP 을 실측 조준간격(≈25틱) 근처로 올려 실제 병목이 되게 해야 한다.
- **도망감소·돌진쿨감이 0 인 것도 국소 미분 때문**이다(대표 빌드가 천장 안쪽에 있다). 경계
  빌드에서는 둘 다 천장을 한 칸 올려 계단만큼 뛴다.
- **수영속도는 %의 절반만 인정**했다(`SWIM_EFF=0.5`) — `WATER_MOVEMENT_EFFICIENCY` 가 비선형이고
  회귀 표본이 없다. 이 가정이 바뀌면 수영속도 열이 비례해 움직인다.
