# 작살 밸런스 감사 지표

## 필수 분모

작살의 시간당 성능은 “좌클릭 횟수”가 아니라 다음을 분리한다.

1. `swing_attempts/h` — 실제 스윙 시도
2. `hit_rate = hits / swing_attempts`
3. `catch_rate = catches / active_minutes`
4. `quality_mean` — 70~100 품질 롤의 실측 평균
5. `money/h = catches/h × 평균 판매가 × 추가마리 배율`
6. `xp/h = catches/h × 등급별 XP × 경험치 보너스`

시뮬레이터의 초기 처리량은 Java 상수 `spawn=5초`, `catch cooldown=7초`, 물고기 HP와 공격력으로 계산한다. 적중률·실제 전투시간은 계측 전까지 별도 가정으로 표시한다.

## 비교 지표

| 지표 | 정상 판정 | 주의 | 치명 |
|---|---:|---:|---:|
| 같은 레벨 최적 작살/낚싯대 골드 비율 | 0.85~1.15 | 1.15~1.50 또는 0.60~0.85 | >1.50 또는 <0.60 |
| 같은 레벨 최적 XP 비율 | 0.85~1.20 | 1.20~1.75 | >1.75 |
| 작살 평균 품질 대비 낚싯대 | 코드상 차이를 보상·위험과 함께 설명 | +10점 이상 | 품질·처리량·실패가 동시에 우세 |
| 작살 내구/재료/보물상자 부담 | 낚싯대와 비용 항목이 명시됨 | 일부 미계측 | 소모 없이 반복 소득만 증가 |
| 실측 표본 | 10명·2시간 이상 또는 1000 catch | 그 미만 | 표본 없이 확정 튜닝 금지 |

비율 하나만으로 즉시 너프하지 않는다. 작살의 물속 진입·조준 난이도·적중률·지역 제한·행동 피로를 함께 계산한다. 다만 1.5배 이상이면서 전용 다운사이드가 없으면 🔴 후보로 올린다.

## 민감도

최소 세 시나리오를 출력한다.

- 보수: 적중률 0.50, 반응/이동시간 +50%
- 기준: 적중률 0.75, 현재 상수 그대로
- 숙련: 적중률 0.90, 반응/이동시간 -25%

세 시나리오 모두에서 우세하면 구조적 문제이고, 기준/숙련에서만 우세하면 숙련 보상으로 분류한다.
