★2026-08-26 신설. 이 스킬은 2026-07-24 부터 넉 달간 «가정 상수»로 돌았다. 그 사이 prod 에는

## 함정 (전부 실측으로 확인했다 — 이걸 모르면 결론이 틀어진다)

1. **op 필터.** `ctx.op == 1` 은 운영자/개발자 플레이다. 이름 기준 `OPS` 집합으로 한 번 더 걸러야
   한다(op 플래그가 없는 이벤트가 있다). 안 걸르면 표본의 25% 가 크리에이티브·무한돈 플레이다.
2. **«세션 시간» ≠ «활성 낚시 시간» (3~4배 차이).** `day_player.playtime_s` 로 나누면 44 포획/h,
   캐스트 간격이 이어지는 구간만 세면 **190 포획/h**. 장비 가치·유지비는 «낚시하는 동안»의
   비율이므로 후자를, 레벨 도달시간·총수입은 전자를 쓴다. pull_players.py 는 둘 다 남긴다.
3. **캐스트 ≠ 시도 ≠ 포획.** 실측 캐스트 249/h → 결과 194/h(전환 62%) → 포획 190/h(완주 97%).
   내구·미끼 소모는 `reduceDurability()` 가 **`fish.result` 1건마다 1회**라 **194/h** 가 맞다.
   구 모델의 259/h(=220÷0.85)는 34% 과대계상이었다.
4. **`fish.result.price` 는 판매보너스까지 반영된 실현가**다(`FishItem.calcPrice`, 신선도는 포획
   직후라 1.0). 즉 «그 플레이어의 실제 장비로 실현된 값»이라 모델 검산에 그대로 쓸 수 있다.
   실제로 모델 «중반 605원/포획» ↔ 실측 «Lv20-29 606원/포획» 이 일치했다 — 어긋난 건 처리량뿐.
5. **`imine.min`/`mine.min` 은 1분 버킷**이다. 버킷 수 = 채굴한 분. 이벤트 수로 나누지 말 것.
6. **커버리지 상한이 곧 결론의 상한이다.** 2026-08-26 기준 관측 최고 레벨 **26**. A/S/G 장비,
   종결 앵커, 늪지대·대양 이후 콘텐츠는 전부 «모델 외삽»이며 실측 근거가 0이다. 리포트에서
   외삽 구간은 반드시 그렇게 표기할 것(item_ledger.py 는 `~` 로 표시한다).
7. **지역 조업 편중.** 실측 포획의 67% 가 항구, 19% 가 강 — 나머지 14 지역이 합쳐 14%. 「그 지역
   전용 재료는 가면 얻는다」는 모델 가정이 현실에서 관측되지 않았다는 뜻이다. 재료 게이트를
   그 지역 확률로 계산하면 «갈 마음이 없는 지역»의 시간을 자유롭게 쓴다고 가정하게 된다.
