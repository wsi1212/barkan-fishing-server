# 아이콘 크래프트 — 깊은 기법

## 1. 바닐라 아이템 아이콘 해부 (16×16)

바닐라 낚싯대(fishing_rod.png)를 뜯어보면 아이콘 문법이 다 나온다:

- **↗ 대각 관례**: 손잡이 좌하단(2,13) 부근 → 팁 우상단(13,2) 부근. 도구/무기 전부
  이 축이다(검·곡괭이·낚싯대). 이 축을 벗어난 도구는 인벤에서 "아이템이 아닌 것"처럼 보인다.
- **두께 문법**: 손잡이 쪽 2~3px → 팁 1px 테이퍼. 16px에서 두께 변화 1px가 곧 원근이다.
- **외곽선**: 퓨어 블랙이 아니라 **그 재질 램프의 최암색**. 그리고 전체를 두르지 않는다 —
  빛 받는 위·왼쪽 모서리는 외곽선을 생략하거나 라이트로 대체(셀아웃).
- **줄(라인)**: 팁에서 1px로 늘어지되 살짝 처짐(sag). 완전 수직 직선은 죽은 줄이다.
- **형태 셰이딩**: 대각 막대 = 누운 원통. 윗면(좌상향 면)에 라이트 1줄, 아랫면에
  코어섀도 1줄. 이 두 줄이 "막대"를 "봉"으로 만든다. `iconlib.shaft`가 자동으로 한다.

## 2. 재질 램프 표준표 (palette.ramp 입력 기본색)

정체성 테이블 작성 시 여기서 시작(필요하면 refboard에서 추출로 교체):

| 재질 | base hex | 비고 |
|---|---|---|
| 생나무 가지 | `6b4a2a` | pixel-forge 가지색과 동일(세계관 일관성) |
| 참나무 | `9a6b38` | 바닐라 oak 판자보다 한 톤 뮤트 |
| 대나무 | `b5a545` | 마디는 r[0]으로 |
| 흑단목 | `3a3140` | 보라 낀 검정, r[4]가 하이라이트로 살아야 함 |
| 사암/사막 | `d8b56a` | 금테(`d4a017`)와 짝 |
| 강철/카본 | `6f7a85` | 슬롯 회색과 붙으므로 반드시 채도 or 명도 이탈 확인(lint 5번) |
| 금 장식 | `d4a017` | 포인트 전용, 면적 금지 |
| 수정/천공 | `7fd4d0` | 반투명 아님 — 밝은 램프로 유리감 |
| 여명 그라데 | `3a2a55`→`f2a14e` | grade_colfn으로 t 그라데이션 |

**강철·은색 계열 경고**: 슬롯 배경 #8B8B8B(휘도 139)와 정면 충돌한다. 반드시
푸른 기(채도)를 넣거나 명도 대비를 키우고, `icon_lint` 5번 게이트로 확인.

## 3. 오오라 설계 (fx)

- **실루엣 우선**: 오오라는 본체 완성 후 바깥에만. 본체 픽셀을 덮는 순간 실루엣이 죽는다.
- **예산**: 본체 불투명 픽셀의 25% 이하. 불꽃 혀 4~6개, 혀당 1~3px.
- **불꽃 색 진행**: 뿌리 r[2](주황) → 중간 r[3] → 혀끝 r[4](밝은 노랑). 위로 갈수록
  밝아지는 게 "불티" 문법. 반대로 하면 젖은 연기처럼 보인다.
- **애니메이션 연속성**: 앵커(뿌리 위치)는 프레임 간 고정, 높이·드리프트만 변주.
  프레임마다 앵커를 재추첨하면 TV 노이즈가 된다. `fx.fire_aura`가 이 규칙을 코드로 보장.
- **frametime**: 3~4틱. 2는 다급하고 6은 슬라이드쇼.
- **색 변주 오오라**: 얼음=`7fd4d0`, 독=`6fae3f`, 신성=`f2e29a`, 바르칸=`2fa39e`.
  같은 fire_aura 엔진에 램프만 바꿔도 되는 영역(오오라는 이펙트라 색칠놀이 규칙 비적용).

## 4. 배지(스킬 아이콘) 구도

- 필드(원형 disk r≈7)+림(selout) → 글리프 → 반짝이 순서.
- 글리프는 **한 형태**: 물고기 1, 곡괭이 1, 물결 1. 두 개체가 필요하면 겹치지 말고
  크기 차등(주 1 + 종 1 작게).
- 필드는 세로 2톤(위 밝음)으로 돔감. 림은 필드 램프의 r[0].
- 글리프 색은 필드와 보색/명도 대비 — 금 글리프+청록 필드가 서버 표준 조합.
- 잠금/미해금 상태는 게임 쪽에서 회색 유리판을 덧대므로, 아이콘 자체를 어둡게 만들 필요 없음.

## 5. 아마추어 티 체크리스트 (배포 전 자문)

1. 필로우 셰이딩? (중앙 밝고 가장자리만 어두운 쿠션) → 광원 좌상단으로 재셰이딩
2. 퓨어 블랙 외곽선 전체 두름? → 램프 최암색 + 셀아웃
3. 직선 자(ruler) 티? 낚싯대가 완전 직선이면 죽은 막대 — 베지어로 1~2px 휘기
4. 슬롯 회색에 묻힘? → lint 5번, 채도나 명도 이탈
5. 모든 아이콘이 같은 톤? → 정체성 테이블로 돌아가 모티프 재분배
6. 오오라가 본체보다 시끄러움? → 예산 25% 재확인
7. 반투명 남발? → 글로우 헤일로 외 전부 알파 255/0 (가구 알파 사고 교훈)
8. 16px에서 안 읽히고 "확대하면 예쁨"? → 확대본은 진실이 아니다. 1× 슬롯 목업으로 판정

## 6. 32×32 승격 기준

기본은 16. 승격은 (a) 도감/GUI 대형 표시 전용 자산, (b) 16에서 글리프 2개 이상이
필수인 배지 — 둘뿐. 장비 아이콘은 항상 16(옆 칸 바닐라와 해상도 이질감 금지).
