# 채집 경제 후속 감사 — 미끼 채집품 연동 — 2026-08-10

## 요약

- 조합 가능한 미끼 레시피 17종 모두에 채집품 재료를 연결했다.
- 미끼 레시피의 채집품 재료는 총 28종, 공식 1회 제작량 합계 89개다.
- 기존 미끼 아이콘·스탯·가격·내구도와 기존 부품 재료는 유지하고, 채집품 재료를 추가했다.
- `지렁이`, `잠수부 미끼`, `심해 잠수부 미끼`는 현재 레시피가 없는 전용 상점 판매품이라 이번 조합대 변경 대상에서 제외했다.
- 수요가 이미 집중된 `라벤더 선반버섯`, `야광버섯`, `트러플`은 새 미끼 재료로 추가하지 않았다.

판정: `조합 미끼 17/17 채집품 연동 / 채집품 28종에 반복 제작 수요 추가 / 고수요 3종 추가 부담 없음`.

## 밸런스 판정

- 1회 미끼 제작이 채집품 2종을 소모하므로 채집품이 일회성 장식이 아니라 낚시 소모품으로 순환한다.
- 미끼는 캐스팅마다 1회 소모되는 구조라, 제작 재료를 추가하는 효과가 낚싯대·장비처럼 한 번 만들고 끝나는 싱크보다 반복성이 높다.
- 희귀 채집품은 핏빛수정초·자수정새싹·사막장미·서리연꽃을 각각 레시피당 1개만 사용한다. 희귀 채집 쿨다운을 기준으로 과도한 병목을 만들지 않도록 제한했다.
- 기존 감사에서 저사용으로 분류한 붉은 요정버섯, 주황 요정버섯, 황금 갓버섯, 이끼 톨버섯, 분홍 겹버섯, 도토리 다발 모두 미끼 레시피에 연결됐다.
- 라벤더 선반버섯(공식량 133), 야광버섯(44), 트러플(36)은 기존 고수요·고단계 레시피가 있어 이번 변경에서 제외했다.

## 검증 결과

- dev `recipes.json`과 실행 중 BlockShip 데이터 `recipes.json`의 P83~P99 레시피가 일치한다.
- 17개 레시피 모두 채집품 재료가 2종씩 들어 있다.
- 추가 채집품 재료 ID 중 `forage-types.json`에 없는 항목은 0개다.
- 추가 재료 ID 중복은 0개다.
- 미끼 결과 아이콘과 부품 스탯/가격 데이터는 변경하지 않았다.

## 후속 모니터링

이번 변경은 채집 노드 수나 쿨다운을 즉시 조정하지 않는다. 실제 `craft.do`에서 미끼 제작량과 `forage.do`의 채집 빈도를 수집한 뒤, 채집품별 재고 체류와 희귀 재료 병목을 다시 확인한다. 특히 A등급 미끼 제작이 활성화된 뒤 서리연꽃·사막장미가 병목인지 확인하고, 필요할 때만 수량을 1단위씩 조정한다.
