## D. 장비 / 강화 / 부품

### 권위 수치

| 항목 | 정상적인 기존 프로필 예 | 현재 문제 프로필 예 |
|---|---|---|
| +1~+4 | 난이도 0 | 매 레벨 난이도 +1 |
| +5 | 난이도 +1 | 난이도 +1 |
| +6 누적 | 난이도 **1** | 난이도 **6** |
| 강화 +6 버튼 | 28,000원 · 성공 65% · 하락 8% · 진주 2 | 동일 |

`대나무 막대기`는 +5에만 `난이도:1`이 있고 +6에는 난이도가 없다. 반면 `거래상의 낚싯대`는 +1~+6 모든 줄에 `난이도:1`이 있어 +6 누적 난이도 6이 된다. 같은 패턴이 실제 `parts.json`의 67개 낚싯대 중 46개에 적용된다.

| 실제 낚싯대 등급 | +6 누적 난이도 6인 수 |
|---|---:|
| D | 4 |
| C | 2 |
| B | 13 |
| A | 27 |
| 합계 | **46 / 67 (68.7%)** |

추가로 이 46개 프로필은 최고 강화 단계의 한 줄에 `난이도:1`이 두 번 들어간다. 예를 들어 `거래상의 낚싯대` +13은 `난이도:1,난이도:1`이고, 일부 A급 +15도 같은 구조다. 그러므로 +10·+13·+15에서는 매 레벨 +1을 넘어 +2가 누적되는 프로필도 있다.

### 왜 사기처럼 느껴지는가

`FishingBonuses`가 강화 누적 `난이도`를 `rodBonus`에 그대로 더하고, `MinigameTables`가 `net = rodBonus - 물고기난이도 - 크기난이도`, `존폭 = 8 + floor(net/2)`로 사용한다. 난이도 +6은 단순 판매 보너스 6%가 아니라 존폭과 바 폭을 동시에 바꾸는 직접 조작 난이도 스탯이다.
