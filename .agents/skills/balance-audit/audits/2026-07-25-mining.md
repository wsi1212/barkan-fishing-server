# 광질(mining) 감사 — 2026-07-25 (베이스라인)

## 요약 (TL;DR)
- 종합 상태: 🟢 **양호** — 초안에서 섬 광산 처리량을 🔴로 판정했으나, **운영자 확인으로 이미 3중
  안전장치가 있음이 밝혀져 철회**(아래 B절 "철회 경위" 참조).
- 첫 감사 — 델타 없음. 이 스냅샷이 향후 비교 기준.
- 광질은 낚시와 근본 구조가 다르다: **순수 소모(money) + 재료생산**, 직접 판매경로 없음(확인:
  `SellCommand`/`SellGuiListener` 무관련).
- **두 시스템은 완전히 별개**(운영자 확인): 섬 광산(island_world/guild_world, 바닐라 마크 광석 —
  돌/석탄/철/구리/금/청금석/다이아/에메랄드) vs 드릴 시스템(mine월드/레드_로드, 흑정석/자수정 전용).

## A. 드릴 채굴 (mine월드/레드_로드)  🟢
| 항목 | 값 |
|---|---|
| 티어 | T1(배속1.0, 3,000원 직구) → T2(배속2.0, 레시피해금 10,000원+Lv15, 압축흑정석8) → T3(배속3.5, 레시피해금 30,000원+Lv30, 압축흑정석16+자수정8) |
| 흑정석계 (mine월드) | 얇은(30틱/180s재생/1개) · 보통(50틱/300s/1~2개) · 풍부한(80틱/480s/1~3개) |
| 자수정계 (레드_로드) | 얇은(40틱/180s/1개) · 보통(60틱/300s/1~2개) · 정동(90틱/480s/1~3개) · 군집(70틱/360s/1~2개) |
| XP | breakTicks÷2 (15/25/40, 자수정 20/30/45/35). **일일캡 없음** |

- **자연 제약 존재**: 파괴시간(T1 기준 1.5~4.5초, T3면 0.43~2.57초)+재생 180~480초. 낚시의
  "미니게임 게이팅"과 유사한 역할 — 시간이 지나야 다시 캘 수 있다. 🟢 설계 의도대로.
  단, **실제 시간당 처리량은 채굴존 광맥 개수(서버 빌드 데이터, 코드에 없음)에 좌우** — 이 수는
  현장 확인 없이 추정 금지(metrics.md 명시).
  - ⚪ **압축흑정석 순환참조**: T2/T3 레시피 자체가 압축흑정석(=흑정석9개 조합)을 요구 →
    T1으로 먼저 캐야 T2/T3를 만들 수 있는 자연스러운 순차 진행. 버그 아님, 설계 확인.
- **직접 판매경로 없음** — 흑정석/자수정은 순수 크래프팅 인풋(압축흑정석·부품 레시피).

## B. 섬 광산 생성기 (island_world/guild_world)  🟢 (초안 🔴 → 철회)
| 항목 | 값 |
|---|---|
| 메커니즘 | 물[공백1~8칸][울타리] → 공백에 광석 자동생성 → 채굴 → 드롭+**즉시 재생**(쿨타임 0) |
| 광석 확률(가중치100 기준) | 돌35% · 석탄19% · 철15% · 구리11%(2~4개) · 금6% · 청금석4%(4~8개) · 다이아5% · 에메랄드5% |
| XP 일일캡 | 500회(`ISLAND_MINE_DAILY_CAP`) — 아이템 드롭 자체는 캡 무관 |

**초안 판정(🔴 처리량 무제한) — 운영자 확인으로 철회.** 코드만 보고 "즉시재생+바닐라파괴속도 그대로
통과 = 엔드게임 곡괭이면 무한 채굴"이라 판정했으나, 실제로는 **3중 안전장치**가 이미 있음을
운영자가 확인:

1. **호퍼(자동수집) 개수 자체가 섬 레벨별로 한도 걸림** — `IslandManager.HOPPER_LIMIT =
   {0,8,16,32,64,128}`(코드 확인). "잠수 태워놓고 방치로 무한 복사"를 막기 위한 설계 — 자동화
   규모가 애초에 캡돼 있어 AFK 대량파밍이 안 됨.
2. **효율4 이상 곡괭이(인챈트북 포함)는 상점에서 안 판다** — 구매로 지름길 없음. 나아가 **인챈트
   테이블 자체에서도 효율5가 안 나옴**(운영자 직접 확인, 서버 실측). 즉 제가 가정한 "네더라이트+
   효율5+헤이스트" 최악 시나리오는 애초에 이 서버에 존재하지 않는 조합.
3. **효율4+헤이스트2로도 "우다다닥" 안 됨**(운영자 직접 확인 — 실측 체감).

세 가지가 독립적으로 겹쳐 막고 있어 실질 리스크는 낮다: (1)이 자동화 규모를, (2)+(3)이 수동 채굴
속도 자체를 상한선 아래로 묶는다. **결론: 섬 광산은 설계 의도대로 안전하게 운용 중 — 조치 불필요.**

- 참고로 남겨둘 점: 일일 500회 XP캡은 스킬 경험치만 멈추고 아이템 획득 자체는 안 막는다(코드
  구조상 사실) — 다만 위 3중 장치로 처리량 자체가 이미 낮게 묶여있어 이 캡의 허점이 실질 문제로
  이어지진 않는다. 순수 참고사항, 조치 불필요.

   현장에서 확인해 실제 시간당 처리량 추정치를 다음 감사에 추가할 것(코드만으론 알 수 없음).
