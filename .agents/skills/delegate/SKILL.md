# 위임 (NVIDIA 오프로드)

`$ARGUMENTS`로 받은 작업을 직접 구현하지 말고, 아래 절차대로 `~/ai-delegate/delegate.py`(NVIDIA `z-ai/glm-5.2`)에 위임한다.
자세한 배경: 프로젝트 메모리 `project_nvidia_delegation_setup` / `feedback_delegate_trivial_tasks`.

## 0. 적합성 먼저 판단 (거절 조건)

다음이면 위임하지 말고 사용자에게 직접 하겠다고 말할 것:
- **BizBen(회사) 코드/데이터가 조금이라도 섞임** — NVIDIA 무료티어는 입출력을 로깅+제3자 공유함. 이 프로젝트(마크 게임) 코드에만 쓴다.
- 작업이 설계 판단·트레이드오프·기존 시스템과의 정합성 확인이 필요한 경우(= "쉬운 작업"이 아님). 이런 건 메인 세션이 직접.
- 정확한 API/시그니처를 스펙에 다 못 박을 만큼 애매한 경우.

적합하면 계속 진행.

## 1. 스펙 작성

`$ARGUMENTS`를 바탕으로 자기완결적 스펙을 만들어 스크래치패드에 파일로 저장한다. 스펙에는 반드시:
- 정확한 대상 파일 경로, 클래스/메서드 시그니처(추측 말고 실제 코드 확인 — 필요하면 `codegraph_search`/`codegraph_explore`로 먼저 조회)
- 입력/출력 포맷, 그리고 "이 API만 써라, 새 메서드/패키지 상상 금지" 명시
- 코드 컨벤션(한글 UI 텍스트, 볼드 금지, Num.fmt 등 — AGENTS.md 참조)

## 2. 위임 실행

```bash
python3 ~/ai-delegate/delegate.py <스펙파일> -o <출력파일>
```

기본 모델은 `z-ai/glm-5.2`(품질 우선, 리즈닝이라 응답 ~30초 — 멈춘 게 아님). glm이 다시 DEGRADED/오류면 `--model openai/gpt-oss-120b`(~8초)로 폴백. `kimi-k2.6`은 NVIDIA 무료티어에서 불안정 이력 있음(메모리 참조).

## 3. 필수 리뷰 게이트

출력을 그대로 적용하지 말 것. 반드시:
1. 스펙대로 구현됐는지, 존재하지 않는 API를 지어내지 않았는지 확인
2. 프로젝트 컨벤션(탭완성, 영타별칭, 볼드금지 등) 준수 확인
3. 문제 있으면 직접 고치거나 스펙을 보강해 재위임
4. 통과하면 실제 파일에 적용(Edit/Write)하고 무엇을 위임했는지 한 줄로 사용자에게 보고
