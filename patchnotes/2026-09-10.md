# 바르칸 열도 패치노트 — 9/7 ~ 9/10

> 나흘치를 묶었습니다. 오늘 06:00 점검까지 적용된 상태입니다.

# 🖥️ 공통

## 신규
- **`/수족관`** — 잡은 물고기를 넣어 전시하는 건축형 수족관. 크기 5단계(미니~특대), 자기 섬에 설치
- **`/복권`** — 500원 즉석복권. 꽝이어도 **가구 1개**(상점가 5,000원), **2% 확률로 수족관 당첨**. 게임머니 전용입니다
- **`/계정이관`** — 부캐·구계정의 진행도를 한쪽으로 합칩니다 (3단 확인)
- **보드게임 3종** — 오목 · 우르 · 쿼리도

## ⛵ 배
- **바이킹 롱쉽** 추가 (캐시 전용)
- **페리가 진짜로 항해합니다** — 갑판에 앉은 채 바다를 건너갑니다 (예전엔 순간이동)
- **조선소 시승** — 배를 **좌클릭**하면 전용 바다 월드에서 무료로 타 볼 수 있습니다 (`/미리보기종료` 로 복귀)
- 속도 표기를 「티어」에서 **최고속도 km/h**로 (30 / 40)

## 📘 튜토리얼 대폭 간소화
- 진행 단계를 **압축**했습니다 — 수제 낚싯대와 첫 강화까지 곧장 이어집니다
- **사이드 퀘스트는 튜토리얼 졸업 후** 열립니다 (초반에 목표가 뒤섞이지 않게)
- 이미 진행 중이던 계정은 **없어진 단계의 보상을 그대로 보전**해 지급합니다

## 🌿 채집 스킬 전면 상향
노드 대기시간이 길고 포인트가 빠듯한 점을 보정해 계열 전체를 올렸습니다.
- 2배 채취 확률 **최대 36% → 50%**
- 희귀 채집물 발견 **2.23% → 4.46%**
- 상시 이동속도 **+8.2% → +16.4%**
- 「지역의 선물」 3% → **5%** · 「숨겨진 보급품」 2% → **3%** · 풍성한 채집 / 직감 1% → **2%**

## ⛏️ 채굴 스킬 — 「탐광」 계열이 「정비」 계열로 교체
- 탐광(희귀 가중·잡석 감소·정밀 탐사·풍부한 광맥)은 광맥·응축과 역할이 겹쳐 폐지했습니다
- 대신 **곡괭이 내구도**를 다루는 정비 계열이 들어갑니다

## ⚖️ 밸런스 (중요)
- **경험치에서 크기 점수를 제거했습니다.** 등급 분포는 그대로인데 마리당 경험치가 8일 만에 7배로 부풀고 있었습니다(상한이 없어 크리 → 찌 → 환경 보너스가 연쇄로 곱해짐). 앞으로는 마리당 경험치가 크기와 무관합니다
- **크리티컬이 판매가를 올리지 않습니다** — 크리는 「크기」에만 작용하고, 크기가 값을 올리는 경로는 그대로입니다
- **낚싯대 난이도 사다리 재배정** — S 8종이 A 하한에 앉아 340만원 낚싯대와 78만원 낚싯대가 같은 난이도였습니다. 하한 B3 / A5 / S7
- **바르칸 연안 어장 신설 52종** — 그 지역에서 「아직 물고기가 없습니다」가 뜨던 상태였습니다
- **S등급 복원** — 마을 종결 작살 5종 + 히든 종결 낚싯대 6종

## 🛡️ 길드 · 멤버십
- 길드 창에 **레벨 진행도 표시** (다음 레벨까지 남은 점수 + 올리는 방법)
- 캐시상점 **길드 부스터** 추가 / 경험치 2배는 겹쳐 사면 **시간 합산**
- **길드 조리대 · 모닥불 시스템 전면 삭제**
- **`/길드 홍보` 폐지 → `/홍보` 하나로 통합**
- 멤버십 작물 혜택이 「레벨 상한」에서 **「개수 +5 / +10 / +20」**으로

## 🐛 큰 버그 수정
- **대장간에 레시피 73종이 안 뜨던 문제** / 왕도 품목이 상점 전체 탭에서 안 보이던 문제 / 어디서도 못 구하던 **사자 릴** 복구
- 지역 이름 변경으로 **조용히 진행 불가가 되던 퀘스트 3개** 복구
- 보물상자 창을 닫으면 서버가 멈추던 문제
- 도감에 **「특별 아이템」 탭** 신설 — 퀘스트 물건 14종이 물고기 도감에 섞여 있었습니다
