## 별도 데이터 이슈

- Citizens ID 3 `할아버지`: 초상화 매니페스트에 항목이 없어 대화 시 기본 초상화 fallback이 발생한다. 현재 초상화-스킨 비교 대상 자체가 없다.
- `모르`, `일곱셋`, `가라앉은하`, `비늘짜는이`, `울지않는것`, `오스발트`: NPC 데이터에는 있으나 Citizens ID가 비어 있어 이번 스킨-초상화 대조에서 제외했다.
