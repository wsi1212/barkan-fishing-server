# `[길잡이] 할아버지` ImageGen pilot

- 대상: `[길잡이] 할아버지`
- Citizens ID: `3`
- 기준 스킨: `skin-forge/out/tf_grandpa.png`
- 목적: BetterHUD 대화창용 캐릭터 초상화

## 스킨 고정 요소

이번 파일은 `낚시꾼할아버지`(Citizens ID 1)가 아니라 정확히 ID 3의 `[길잡이] 할아버지` 스킨을 기준으로 생성했다.

- 빛바랜 적갈색/갈색의 밀착형 모자
- 회백색 머리카락, 눈썹, 수염
- 청록색 칼라/목 부분
- 짙은 적갈색 긴 조끼·겉옷
- 크림색 셔츠와 소매
- 회갈색 바지와 어두운 신발
- 밀짚모자, 청록색 낚시 조끼, 다른 NPC의 물고기 소품은 사용하지 않음

## 상태 설계

| 파일 | 상태 | 대사/퀘스트 근거 |
|---|---|---|
| `base.png` | 기본·인사 | `[인사]`의 환영, 낚시 원칙 설명, 낡은 나뭇가지 전달 |
| `teaching.png` | 설명·가르침 | “내가 하나씩 가르쳐주마.” 및 튜토리얼 안내 대사 |
| `progress.png` | 진행 중·차분한 지도 | `[진행중]`의 “서두르지 말거라”, 화살표를 따라가라는 안내 |
| `final_exam.png` | 마지막 시험·엄숙하지만 격려 | `튜토11` 진행 중: B등급을 잡아오라는 마지막 시험 |
| `graduation.png` | 퀘스트 완료·자랑스러운 미소 | 일반 완료 및 `튜토11` 완료: 진짜 어부 선언, 졸업 선물, 작별 |
| `farewell.png` | 졸업·애틋한 작별 | “언제든 /섬으로 돌아갈 수 있어.”, “네 바다를 찾으렴.” |

모든 원본 PNG는 ImageGen 생성 후 녹색 작업 배경을 제거한 RGBA 투명 이미지다. `framed/`에는 두 번째 `progress` 이미지를 기준으로 alpha 폭·상단 위치를 맞추고, 발끝처럼 대화창에 불필요한 하단이 잘리지 않도록 통일한 대화창용 버전이 들어 있다.

실제 전체 NPC 생성은 이 보정된 1명 시트에 대해 사용자 검수를 먼저 받은 뒤 진행한다.
